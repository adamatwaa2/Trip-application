# Pirates of the Red Sea visual assets

- `public/media/pirates/pirates-original-parchment-logo.webp`: deterministic crop of the original logo collection supplied by the site owner. No generated artwork is used.
- `public/media/pirates/sailing-opening.mp4`: an eight-second, silent, compressed excerpt of real sailing footage by Tatiana Tzviatkova, published on Pexels on 13 September 2024. Source: https://www.pexels.com/video/a-pirate-ship-is-sailing-in-the-ocean-28409851/
- `public/media/pirates/sailing-poster.jpg`: frame extracted from that same video.
- License checked 2 November 2026: https://www.pexels.com/license/ allows free website use and modification. Credit is provided beside the film. The vessel and location are illustrative stock footage, not representations of the booked boat or route.
- Compass, wheel, anchor, chest and story-map graphics are inline SVG interface elements. Paper treatment uses CSS; no generated raster illustration is included.

The public trip remains a concept with a provisional April–May 2027 window. The booking route shows the same identity and an honest closed-registration state. A published direct-booking trip uses the existing booking engine within the themed frame; payment and booking validation are unchanged.

Pirata One is locally bundled for this experience's display headings under its included SIL Open Font License. The main Planet Infinity body and UI font is retained.
